# MediaLog Bootcamp

Paquete `medialog-bootcamp`. Node >=22.22.0, pnpm 11.17.0.

## Sesión 06 · Entrada

Desde session-05-end se añade MediaDetailContent y CSS de soporte. No hay Mantine, selección, modal ni callbacks en las tarjetas. Las instrucciones completas están después de la presentación continua en el material de clase.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Comprueba con `pnpm build` y `pnpm lint`. Guarda cambios antes de cambiar de rama. Filtros, contador y limpieza se conservan.

# MediaLog Bootcamp

Paquete `medialog-bootcamp`. Node >=22.22.0 y pnpm 11.17.0.

## Sesión 05 · S05-B06 · Vacíos por causa

hasActiveFilters considera texto efectivo o tipo. Una fuente vacía mantiene Catálogo vacío. Contador y limpieza quedan para la práctica, aún sin solución.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

En otra terminal: `pnpm build` y `pnpm lint`.

Primero presentación continua, después editor, práctica y cierre oral. Guarda cambios antes de consultar otra rama. Las ramas anteriores conservan el progreso 01–04; la entrada 05 coincide con session-04-end.
